# Gamedev

Репозиторий для изучения разработки игр, создания учебных проектов и хранения справочных материалов.

Основные направления — 2D-игры на Godot и браузерные игры на Phaser. Каждый проект развивается независимо и содержит собственное краткое описание, концепцию и план разработки.

Работа строится небольшими этапами: идея, прототип, полный игровой цикл, наполнение, оформление и проверка. Сначала проверяем основные механики, затем расширяем игру.

Общие руководства и идеи служат справочными материалами. Требования и технические решения конкретной игры фиксируются в её документации.
