# Идеи вне MVP — «Лесной светлячок»

Эти идеи не должны задерживать первую законченную версию. Добавлять их только после того, как MVP стабильно запускается, играется, сохраняет рекорд и проходит тестирование.

## Погода и окружение

- Ветер, который слегка сносит светлячка в сторону.
- Дождь с редкими вспышками далёкой молнии.
- Туман, меняющий видимость и цвет сцены.
- Звёздное небо с редкими падающими звёздами.
- Свет луны, меняющийся между биомами.

## Запас света

- Ограниченный запас энергии свечения.
- Цветы и частицы, временно восстанавливающие свет.
- Затемнение экрана при почти пустом запасе.
- Уровни с разной скоростью расхода света.

Эту систему вводить только после проверки, что она не превращает спокойную аркаду в раздражающую игру на выживание.

## Новые препятствия

- Движущиеся ветки.
- Паутина, которая постепенно закрывает проход.
- Листья, летящие по ветру.
- Хищная птица как редкое простое препятствие.
- Водопад или ручей, меняющий траекторию полёта.

Каждое новое препятствие должно иметь заметное визуальное предупреждение и не должно требовать реакции быстрее, чем позволяет управление.

## Цветы и взаимодействие с лесом

- Цветы, раскрывающиеся при приближении светлячка.
- Редкие цветы с бонусными очками.
- Растения, которые освещают безопасный путь.
- Грибные поля с разными цветами свечения.
- Маленькие дружелюбные светлячки на заднем плане.

## Новые биомы

- Лунная поляна.
- Тёмное болото с отражениями.
- Старая роща с огромными деревьями.
- Осенний лес с падающими листьями.
- Снежный ночной лес.

Для каждого биома достаточно поменять палитру, фон, частицы и набор препятствий; основное управление должно оставаться прежним.

## Отдельные уровни

- Короткие уровни с фиксированным маршрутом.
- Испытание на время.
- Уровень без частиц для тренировки.
- Уровень с заранее заданными сложными шаблонами.
- Финальный уровень с безопасным полётом к гнезду.

## Путешествие к гнезду

- Карта маршрута через несколько участков леса.
- Небольшая история о поиске гнезда.
- Встреча с другими светлячками.
- Финальная сцена возвращения домой.

Эта идея заменяет бесконечный режим только в отдельном будущем проектном направлении; она не нужна для первого MVP.

## Доступность и удобство

- Переназначение клавиши управления.
- Режим повышенного контраста.
- Уменьшение интенсивности свечения.
- Настройка скорости игры для тренировки.
- Полностью отключаемая музыка.

## Технические идеи

- Пул объектов для препятствий и частиц.
- Replay лучшего полёта.
- Seed для воспроизводимых забегов.
- Режим отладки с отображением хитбоксов.
- Экспорт в браузер и Android после стабильной Windows-версии.
