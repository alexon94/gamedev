# План реализации «Лесного светлячка»

Функциональные этапы проекта. Концепция и игровые правила находятся в `GDD.md`. Пункты отмечаются после проверки, а не только после написания кода. Основание текущих отметок — подтверждения пользователя о работе функций, просмотр кода и автоматические тесты логики. Итоговые проверки всего этапа выполняются отдельно.

## 1. Основной игровой процесс

- [x] Игрок и управление высотой полёта.
- [x] Плавный подъём и падение, ограничение игровой области.
- [x] Движение мира и ветки с проходами.
- [x] Столкновение с препятствием и завершение попытки.
- [x] Бесконечное продолжение маршрута и удаление ушедших объектов.
- [x] Собираемые частицы с одноразовым начислением награды.
- [x] Очки за время полёта и сбор частиц.
- [x] Полный сброс состояния между попытками.

Готовность: пять последовательных попыток без ошибок, повторного начисления наград и объектов прошлой попытки.

## 2. Экраны, пауза и рекорд

- [x] Главное меню: название, рекорд, старт и подсказка управления.
- [x] Игровой интерфейс: текущий счёт и рекорд.
- [x] Экран результатов: счёт, рекорд и сообщение о новом рекорде.
- [x] Повтор кнопкой и клавишей R, возврат в меню.
- [x] Пауза и продолжение по Esc и кнопке.
- [x] Автоматическая пауза при потере фокуса, явное продолжение и сброс удержания.
- [x] Сохранение рекорда между запусками.
- [x] Работа при отсутствии, повреждении или недоступности сохранения.
- [ ] Очистка обработчиков и состояния при переходах.

Готовность: все переходы работают без перезагрузки страницы; на паузе мир и счёт стоят, рекорд восстанавливается при доступном хранилище.

## 3. Разнообразие и баланс

- [x] Разные шаблоны верхних и нижних веток.
- [x] Паутина как дополнительная опасность.
- [x] Разнообразие последовательностей с ограничением повторов.
- [x] Контроль достижимости соседних проходов.
- [x] Постепенное увеличение скорости и сложности с заданными пределами.
- [x] Безопасное размещение частиц.
- [ ] Настройка отзывчивости, наград и темпа попытки.
- [ ] Проверка начальной и предельной сложности.

Готовность: маршрут разнообразен, а проходы остаются достижимыми; устранены нечестные сочетания, найденные в пробных попытках.

## 4. Оформление и звук

- [x] Графика светлячка, веток, паутины и частиц вместо временных фигур.
- [x] Ночной лес с несколькими слоями параллакса.
- [x] Свечение и анимация игрока и частиц.
- [x] Эффекты сбора, столкновения и нового рекорда.
- [x] Читаемый интерфейс в едином стиле.
- [x] Фоновый звук и звуковая обратная связь.
- [x] Отключение звука и корректная работа без него.
- [ ] Проверка лицензий ресурсов.

Готовность: объекты и опасности различимы, оформление помогает понимать события, звук управляем.

## 5. Проверка и готовность MVP

- [ ] Все критерии готовности из GDD.
- [ ] Повторные попытки, переходы, пауза и сохранения.
- [ ] Разные размеры окна и два целевых браузера.
- [ ] Отсутствие ошибок в консоли и бесконечного накопления объектов.
- [ ] Проверка производительности и исправление обнаруженных проблем.
- [ ] Пробная игра другим человеком без объяснений.
- [x] Актуальное описание запуска и известных ограничений.

Готовность: проверенную версию можно передать другому человеку для самостоятельного запуска.

## 6. Внешние текстуры и спрайты

Выполняется после завершения и проверки MVP как отдельное улучшение оформления. Текущая графика остаётся рабочим вариантом; внешние ресурсы не являются обязательным условием готовности MVP.

- [ ] Определить единый стиль, палитру и размеры изображений на основе визуального концепта.
- [ ] Подготовить спрайт светлячка и кадры анимации полёта.
- [ ] Подготовить отдельные слои ночного леса для параллакса.
- [ ] Подготовить изображения веток, паутины и собираемых частиц.
- [ ] Проверить происхождение, лицензии и необходимые указания авторства ресурсов.
- [ ] Подключить изображения и спрайт-листы в игру, заменив выбранные процедурные элементы.
- [ ] Настроить масштаб, точки привязки, прозрачность и фильтрацию изображений.
- [ ] Сохранить текущие размеры хитбоксов, проходы и правила движения; проверить соответствие изображения опасной области.
- [ ] Сохранить программное свечение, эффекты и интерфейс там, где это удобно.
- [ ] Проверить стыки фоновых слоёв, читаемость препятствий, анимации, загрузку и работу на паузе.

Готовность: выбранные внешние ресурсы образуют единый стиль, корректно загружаются и не меняют проверенное управление и честность столкновений. После замены графики повторно проверяются столкновения, читаемость и производительность.

Выполняется после отдельного решения о публикации.

- [ ] Выбор площадки и проверка требований.
- [ ] Описание игры и изображения для страницы.
- [ ] Размещение готовой версии.
- [ ] Проверка запуска, ресурсов, звука и сохранений по конечному адресу.
- [ ] Сбор отзывов и приоритизация следующих исправлений.

Готовность: игра доступна игрокам, определены приоритеты следующей версии.

## Текущее состояние

Пользователь подтвердил основные механики, экраны, паузу, рекорд, разнообразие препятствий, оформление и звук. Исправлено освобождение аудиоресурсов при полном завершении игры. Добавлены проверки повреждённых сохранений, ошибок хранения и повторных аудиоциклов.

Автоматически прошли 14 тестов: 4 генератора, 4 рекорда и 6 управления звуком. Это проверки логики, а не реального рендера, частоты кадров или полного жизненного цикла Phaser.

Перед готовностью MVP остаются:

- Пять последовательных игровых циклов с наблюдением за ошибками и остаточными объектами.
- Проверка размеров окна и второго браузера.
- Длительная попытка с оценкой предельной сложности и производительности.
- Пробная игра другим человеком без объяснений.
- Финальная проверка лицензий зависимостей и ресурсов перед передачей версии.
- Сборка и проверка именно собранной версии — отдельный согласованный шаг.

Графика и звук создаются кодом; внешние изображения и аудиофайлы в игре не используются. Предельные численные параметры генератора проверены тестами, окончательный игровой баланс не считается завершённым.
