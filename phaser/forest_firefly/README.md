# Лесной светлячок

Учебная браузерная 2D-аркада на Phaser и JavaScript. Управляйте высотой полёта светлячка, обходите ветки и паутину, собирайте светящиеся частицы и побейте рекорд.

Планируемое управление: удержание пробела — подъём, отпускание — снижение; `Esc` — пауза, `R` после поражения — повтор.

Статус: подготовлены концепция и план разработки. Код игры ещё не создан, инструкция запуска появится вместе с рабочим проектом.

- [GDD](GDD.md) — концепция, правила и будущие идеи.
- [Plan](Plan.md) — этапы создания и технические решения.
