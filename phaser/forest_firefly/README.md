# Лесной светлячок

Браузерная 2D-аркада: летите через ночной лес, обходите ветки и паутину, собирайте частицы и побейте свой рекорд.

## Как играть

Нажмите «Начать игру». Удерживайте `Пробел`, чтобы подниматься, и отпускайте, чтобы снижаться. Столкновение с веткой или паутиной завершает попытку.

- `Esc` — пауза и продолжение.
- `R` на экране результатов — новая попытка.
- Кнопки меню, повтора и звука нажимаются мышью.
- Каждая полная секунда полёта даёт 1 очко, собранная частица — 10 очков.

При уходе с вкладки игра приостанавливается. Для продолжения нажмите `Esc` или «Продолжить». Звук можно отключить в меню, на паузе и в результатах.

Рекорд и настройка звука сохраняются в текущем браузере для текущего адреса сайта. Игра рассчитана на компьютер с клавиатурой.

## Запуск

Нужны Node.js и npm. Проверенная версия Node.js — 24.11.1.

Откройте терминал в папке этой игры и установите зависимости:

```powershell
npm ci
```

Запустите локальный сервер:

```powershell
npm run dev
```

Откройте адрес, который появится в терминале. Для остановки сервера нажмите `Ctrl+C`. При следующих запусках достаточно `npm run dev`.

## Запуск собранной версии

```powershell
npm run build
npm run preview
```

Первая команда создаёт сборку в `dist`, вторая запускает её локальный просмотр. Откройте адрес из терминала.

## Зависимости

- Phaser 3.90.0 — игровой фреймворк.
- Vite 8.3.5 — сервер разработки и сборщик.

Точные версии зависимостей фиксируются в `package.json` и `package-lock.json`.
